# OneLauncher

> 极速、极致轻量、零负担的 Windows 原生启动器 (Spotlight for Windows)

## 特性亮点
- ⚡ **极致性能**：Rust 原生开发，无 GC、无 Chromium/Electron 臃肿层，常驻内存仅 ~10-15MB，微秒级极速响应。
- ⌨️ **全局唤出**：默认 `Alt + Space` 瞬时呼出/隐藏，仿 macOS Spotlight 优雅体验。
- 🔍 **应用快搜**：自动索引系统开始菜单、UWP 商店应用、便携软件目录，支持中文拼音首字母模糊匹配。
- 🚀 **Everything 原生联动**：基于 Windows IPC 内存消息通道对接 Everything，毫秒级海量文件秒搜。
- 📝 **极简配置哲学**：零冗余 UI 设置界面，基于 `config.toml`，支持外部编辑器随心定制，保存即热重载。
